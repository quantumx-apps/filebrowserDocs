Before upgrading to v2.0.0, convert your existing `config.yaml` with the browser-based config migration tool.

Paste your v1 config, review highlighted changes, and copy the v2 output into your deployment. See {{< doclink path="getting-started/v2/migration/" text="Migration guide" />}} for the full upgrade process.

## Open the tool

<p><a href="/tools/config-migration/"><strong>Open config migration tool</strong></a></p>

The tool runs entirely in your browser. No config data is sent to a server.
